# 预算方案详情原型

入口：统一菜单「预算管理 → 预算方案」。默认打开「奖金提成」。

## 已确认范围

- 复刻提供的预算方案详情截图，保留预算测算步骤及预算统计区。
- 「非人力成本预算」之后增加「奖金提成」页签。
- 五列依次为：组织、组织长名称、职族、职类、奖金总额。
- 组织查询入口是「组织」列表头右侧的漏斗图标；行内组织为普通文本。
- 页签同行右侧使用白底描边「导入⌄」下拉按钮，菜单项为「导入奖金提成」，点击菜单项打开文件选择弹窗。

## 组件映射

| 页面内容 | 原型实现 | 开发组件 |
| --- | --- | --- |
| 预算统计 | 指标卡 | CardView |
| 奖金提成表格 | proto-table / a-table | dynamic-table |
| 组织表头查询 | a-popover + a-input + 查询、重置 | DropdownInputShell / MyInput |
| 导入文件入口 | a-modal + a-upload-dragger | UploadFileModal |

## 演示边界和待确认项

- 数据全部为示例，沿用来源截图的统计值；奖金数据是否纳入总预算、如何测算，未定义。
- 查询演示按组织名称包含关键词匹配，忽略英文大小写；查询规则可后续调整。
- 导入仅演示本地选择 .xlsx/.xls 文件，不上传文件，不解析内容，不写入表格，也不提示导入成功。模板、匹配键、覆盖规则及错误反馈待确认。
- 原截图未提供人力成本明细，本次展示空态；非人力成本预算使用原截图示例。
- 编制规划按钮跳转到现有组织规划，其他既有页面未变更。

## 已验证

- 组织列头查询「销售」得到两条；无匹配显示空态；重置恢复六条。
- 三个页签切换及导入弹窗打开、关闭。
- 1440×900、1280×800 视觉检查；浏览器无运行错误和警告。
- HTML 静态检查、JavaScript 语法检查、现有导航契约检查通过。
