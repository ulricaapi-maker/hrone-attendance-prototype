# 考勤统一原型

独立发布的 HRONE 考勤统一原型，用于集中查看假期方案、额度管理、假勤流程、团队假期和我的假勤。

## 使用方式

- 默认入口：`index.html`
- 默认页面：`基础配置－假期方案`
- 本地服务：在本目录执行 `python3 -m http.server 4173 --bind 127.0.0.1`
- 浏览地址：`http://127.0.0.1:4173/`

## 菜单树

- 基础配置
  - 假期方案
- 额度管理
  - 假期余额
  - 调休假明细
  - 年假结算
  - 病假结算
  - 调休假结算
- 假勤流程
  - 休假
- 团队假期
  - 团队假期余额
  - 团队休假
- 我的假勤
  - 我的假期余额
  - 我的休假-PC端
- 我的休假-移动端（新标签直接打开已发布的最新移动端原型）
