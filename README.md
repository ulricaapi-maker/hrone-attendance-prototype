# 考勤统一原型

独立发布的 HRONE 考勤统一原型，用于集中查看假期方案、成本分摊特例、额度管理、假勤流程、团队假期和我的假勤。

## 使用方式

- 默认入口：`index.html`
- 默认页面：`基础配置－假期方案`
- 本地服务：在本目录执行 `python3 -m http.server 4173 --bind 127.0.0.1`
- 浏览地址：`http://127.0.0.1:4173/`

## 预算规划

- 菜单：预算管理 → 预算规划。
- 入口：`08-预算管理/01-预算规划/index.html`。
- 第一步为组织调整，第二步为职位、编制与人员规划，含规划结果预览、导出及示例预算测算。
- 已包含客户运营部、客户运营经理/专员，以及对应两份新增空编示例。初次打开组织页时安装组织示例，进入第二步时安装职位及编制示例，保留已有浏览器草稿。
- 人员拉取和预算测算使用本地示例数据；导入仅保留入口。草稿保存于当前浏览器，站点不连接实际组织、人员数据接口。
- 保留现有业务系统测算明细链接，访问该业务系统需相应登录权限。
